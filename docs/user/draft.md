# Diary ～Do It and Review Yourself～

## 概要・機能
- 日記アプリ
- 日記に登録できる項目
    - 日付
    - 天気
    - タイトル
    - 出来事
    - 感情
    - 良かったこと
    - 反省点
    - 感謝したこと
    - 明日の目標
    - 明日の楽しみ
    - 学んだこと・気づき
    - 健康・習慣チェック
    - 今日を一言で
    - 自由記述欄
    - 画像
    - 音声
- 出来事、感情、良かったこと、反省点、感謝したこと、明日の目標、明日の楽しみ、学んだこと・気づき、健康・習慣チェック、今日を一言で、これら10項目については設定画面で、日記の登録画面に入力欄を表示するかどうか設定できるようにする
- 日記に公開・非公開を設定できるようにして、みんなの日記ページで共有できるようにする
- デザインは `DESIGN.md` を参照すること
