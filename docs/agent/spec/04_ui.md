## 2. 共通コンポーネント

### 2.1 ヘッダー（`Header`）

- ロゴ / アプリ名（左側）
- ナビゲーションリンク: `みんなの日記`（ログイン不問）
- 認証済み: `日記一覧`, `設定`, ユーザーメニュー（アイコン + ドロップダウン）
- 未認証: `ログイン` ボタン
- ダークモード切り替えボタン（`ModeToggle`）

### 2.2 ユーザーメニュー（`UserMenu`）

ドロップダウン内:
- ユーザー名・メールアドレス表示
- `設定` リンク
- `ログアウト` ボタン

### 2.3 天気アイコン

晴れ / 曇り / 雨 / 雪 / その他 に対応する絵文字またはアイコンを表示。

### 2.4 感情バッジ

| 値 | 表示ラベル | 色 |
|---|-----------|---|
| `great` | とても良い | primary |
| `good` | 良い | secondary |
| `neutral` | 普通 | outline |
| `bad` | 悪い | tertiary |
| `terrible` | とても悪い | error |

### 2.5 ページネーション

- 「前へ」「次へ」ボタン
- 現在のページ番号と総ページ数を表示

## 3. 画面詳細

### 3.1 ランディングページ（`/`）

**目的**: アプリの概要を伝え、ログイン / 登録へ誘導する

**レイアウト**

```
┌─────────────────────────────────────────────────────────┐
│ Header（ロゴ + ログインボタン）                           │
├─────────────────────────────────────────────────────────┤
│ Hero                                                     │
│   display-lg: "Diary"                                    │
│   headline-md: "Do It and Review Yourself"               │
│   body-md: アプリ説明文                                   │
│   [はじめる] [みんなの日記を見る]                         │
├─────────────────────────────────────────────────────────┤
│ 機能紹介セクション（3カラム）                             │
│   [記録する] [振り返る] [シェアする]                      │
└─────────────────────────────────────────────────────────┘
```

**遷移**
- 認証済みユーザーは `/diary` へリダイレクト

---

### 3.2 ログイン / アカウント登録ページ（`/login`）

**目的**: 既存ユーザーのログイン・新規ユーザーの登録

**レイアウト**

```
┌──────────────────────────────────────────┐
│ ロゴ                                      │
│ タブ: [ログイン] [アカウント登録]          │
│                                           │
│ ── ログインフォーム ──                    │
│  メールアドレス [input]                   │
│  パスワード    [input] [👁アイコン]       │
│  [ログイン]                               │
│                                           │
│ ── 登録フォーム ──                        │
│  お名前        [input]                    │
│  メールアドレス [input]                   │
│  パスワード    [input] [👁アイコン]       │
│  パスワード確認 [input] [👁アイコン]      │
│  [アカウント登録]                         │
└──────────────────────────────────────────┘
```

**バリデーション**

| フィールド | ルール |
|-----------|-------|
| 名前 | 必須、1〜50文字 |
| メール | 必須、メール形式 |
| パスワード | 必須、8文字以上 |
| パスワード確認 | 必須、パスワードと一致 |

**動作**
- ログイン成功 → `/diary` へ遷移
- 登録成功 → `/diary` へ遷移
- 失敗 → `toast.error` でエラー表示
- パスワード欄: 目のアイコンをクリックで平文 / マスク切り替え
- 認証済みユーザーは `/diary` へリダイレクト

---

### 3.3 日記一覧ページ（`/diary`）

**目的**: 自分の日記を一覧表示し、新規作成へ誘導する

**レイアウト**

```
┌──────────────────────────────────────────────────────────┐
│ Header                                                    │
├──────────────────────────────────────────────────────────┤
│ タイトル: "わたしの日記"    [+ 新しい日記]                │
│ 検索バー [                                 🔍]            │
├──────────────────────────────────────────────────────────┤
│ 日記カード（繰り返し）                                    │
│  ┌──────────────────────────────────────────────────┐   │
│  │ 日付  天気アイコン  🔒or🌐（公開状態）            │   │
│  │ headline-sm: タイトル                             │   │
│  │ body-md: 今日を一言で（設定 ON の場合）or 冒頭文   │   │
│  │ 感情バッジ                                        │   │
│  └──────────────────────────────────────────────────┘   │
├──────────────────────────────────────────────────────────┤
│ ページネーション                                          │
└──────────────────────────────────────────────────────────┘
```

**動作**
- カードクリック → `/diary/:id`
- 「+ 新しい日記」クリック → `/diary/new`
- 検索バー入力 → タイトル・自由記述欄のあいまい検索

---

### 3.4 日記作成ページ（`/diary/new`）

**目的**: 新しい日記を入力・保存する

**レイアウト**

```
┌──────────────────────────────────────────────────────────┐
│ Header                                                    │
├──────────────────────────────────────────────────────────┤
│ ← 戻る  "新しい日記"                                     │
├──────────────────────────────────────────────────────────┤
│ 日付 [DatePicker]   天気 [天気セレクター]                 │
│ タイトル [input]                                         │
│                                                           │
│ ── 設定 ON の項目のみ表示 ──                              │
│ 出来事         [textarea]                                 │
│ 感情           [感情セレクター]                           │
│ 良かったこと   [textarea]                                 │
│ 反省点         [textarea]                                 │
│ 感謝したこと   [textarea]                                 │
│ 明日の目標     [textarea]                                 │
│ 明日の楽しみ   [textarea]                                 │
│ 学んだこと     [textarea]                                 │
│ 健康・習慣チェック [チェックリスト]                       │
│ 今日を一言で   [input]                                   │
│                                                           │
│ ── 常に表示 ──                                           │
│ 自由記述欄     [textarea]                                 │
│                                                           │
│ 画像を追加 [ファイル選択] (最大5枚)                      │
│   [サムネイル x N] 各画像に削除ボタン                    │
│ 音声を追加 [ファイル選択] (最大1件)                      │
│   [音声プレイヤー] 削除ボタン                             │
│                                                           │
│ 公開設定: [非公開 ●  公開]（トグル）                    │
│                                                           │
│               [保存する]                                  │
└──────────────────────────────────────────────────────────┘
```

**バリデーション**

| フィールド | ルール |
|-----------|-------|
| 日付 | 必須 |
| タイトル | 必須、最大100文字 |
| 今日を一言で | 最大100文字 |
| 画像 | JPEG/PNG/WebP、各10MB以下、最大5枚 |
| 音声 | MP3/WAV/M4A、50MB以下、最大1件 |

---

### 3.5 日記詳細ページ（`/diary/:id`）

**目的**: 日記の内容を全項目閲覧する

**レイアウト**

```
┌──────────────────────────────────────────────────────────┐
│ Header                                                    │
├──────────────────────────────────────────────────────────┤
│ ← 戻る                          [編集] [削除]            │
│ 日付 / 天気アイコン / 公開状態バッジ                     │
│ display-lg: タイトル                                      │
│ 感情バッジ   今日を一言で                                 │
├──────────────────────────────────────────────────────────┤
│ 各項目（入力値がある項目のみ表示）                        │
│  出来事 / 良かったこと / 反省点 / 感謝 ...               │
│  健康・習慣チェック（チェック状態を表示）                 │
│  自由記述欄                                               │
├──────────────────────────────────────────────────────────┤
│ 添付画像（横スクロールまたはグリッド）                   │
│ 添付音声（プレイヤー）                                    │
└──────────────────────────────────────────────────────────┘
```

**動作**
- 「編集」クリック → `/diary/:id/edit`
- 「削除」クリック → 確認ダイアログ → 削除後 `/diary` へ遷移
- 非公開日記に他ユーザーがアクセス → 403 エラーページ表示

---

### 3.6 日記編集ページ（`/diary/:id/edit`）

**目的**: 保存済みの日記を編集する

- 日記作成ページ（3.4）と同一レイアウト
- 既存データをフォームに初期値としてセット
- 「更新する」ボタンで保存 → `/diary/:id` へ遷移

---

### 3.8 みんなの日記詳細ページ（`/public/:id`）

**目的**: 公開日記を閲覧する（ログイン不要）

- ヘッダーに「投稿者: [名前]」を表示

## 4. ルーティング定義

```
/
├── (認証不要)
│   ├── /                    ランディングページ
│   ├── /login               ログイン / アカウント登録
│   ├── /public              みんなの日記一覧
│   └── /public/:id          みんなの日記詳細
│
└── (認証必要 / 未認証は /login へリダイレクト)
    ├── /diary               日記一覧
    ├── /diary/new           日記作成
    ├── /diary/:id           日記詳細
    ├── /diary/:id/edit      日記編集
    └── /settings            設定
```

## 5. エラー画面

| 状況 | 表示 |
|------|------|
| 404 (Not Found) | 「ページが見つかりません」+ トップへ戻るリンク |
| 403 (Forbidden) | 「このページを表示する権限がありません」+ トップへ戻るリンク |
| 500 (Server Error) | 「サーバーエラーが発生しました」+ 再読み込みボタン |
