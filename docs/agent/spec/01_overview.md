# 全体概要仕様書

## 1. プロダクト概要

| 項目 | 内容 |
|------|------|
| プロダクト名 | Diary ～Do It and Review Yourself～ |
| 種別 | Web アプリケーション（SPA + REST/RPC API） |
| 目的 | 日々の出来事・感情・振り返りを記録し、自己成長を促す日記アプリ |

---

## 2. 技術スタック

| 層 | 技術 |
|----|------|
| フロントエンド | React, TanStack Router, TanStack Query, TanStack Form |
| スタイリング | Tailwind CSS, shadcn/ui 系コンポーネント (`@better-t-app/ui`) |
| API 通信 | oRPC（型安全 RPC、OpenAPI 対応） |
| 認証 | better-auth（メール + パスワード認証、Cookie セッション） |
| バックエンド | Hono（Bun ランタイム） |
| データベース | SQLite + Drizzle ORM |
| バリデーション | Zod |
| モノレポ管理 | Turborepo + Bun workspaces |
| Lint / Format | Biome |

---

## 3. 機能一覧

### 3.1 認証機能

| 機能 | 説明 |
|------|------|
| アカウント登録 | 名前・メールアドレス・パスワード（確認欄あり）で新規登録 |
| ログイン | メールアドレス・パスワードでログイン |
| ログアウト | セッションを破棄してログアウト |

### 3.2 日記機能

| 機能 | 説明 |
|------|------|
| 日記作成 | 下記「日記登録項目」を入力して保存 |
| 日記編集 | 保存済みの日記を編集 |
| 日記削除 | 保存済みの日記を削除（論理削除） |
| 日記一覧 | 自分の日記を日付降順で一覧表示（ページネーション対応） |
| 日記詳細 | 特定の日記を全項目表示 |
| 公開 / 非公開設定 | 日記ごとに公開状態を切り替え |

### 3.3 日記登録項目

| # | 項目名 | 表示設定対象 | 型 | 必須 |
|---|--------|------------|---|------|
| 1 | 日付 | - | date | ✓ |
| 2 | 天気 | - | enum (晴れ/曇り/雨/雪/その他) | - |
| 3 | タイトル | - | string (最大100文字) | ✓ |
| 4 | 出来事 | ✓ | text | - |
| 5 | 感情 | ✓ | enum (とても良い/良い/普通/悪い/とても悪い) | - |
| 6 | 良かったこと | ✓ | text | - |
| 7 | 反省点 | ✓ | text | - |
| 8 | 感謝したこと | ✓ | text | - |
| 9 | 明日の目標 | ✓ | text | - |
| 10 | 明日の楽しみ | ✓ | text | - |
| 11 | 学んだこと・気づき | ✓ | text | - |
| 12 | 健康・習慣チェック | ✓ | JSON (チェックリスト) | - |
| 13 | 今日を一言で | ✓ | string (最大100文字) | - |
| 14 | 自由記述欄 | - | text | - |
| 15 | 画像 | - | file (JPEG/PNG/WebP, 最大10MB/枚, 最大5枚) | - |
| 16 | 音声 | - | file (MP3/WAV/M4A, 最大50MB/件, 最大1件) | - |

> **「表示設定対象」の 10 項目**は設定画面で入力欄の表示 / 非表示を切り替え可能。

### 3.4 みんなの日記機能

| 機能 | 説明 |
|------|------|
| 公開日記一覧 | 全ユーザーの公開日記を日付降順で一覧表示（ログイン不要） |
| 公開日記詳細 | 特定の公開日記を閲覧（ログイン不要） |

### 3.5 設定機能

| 機能 | 説明 |
|------|------|
| 表示項目設定 | 日記作成・編集画面で表示する項目（10 項目）を ON/OFF |
| 健康・習慣チェック設定 | 健康・習慣チェック欄のチェック項目を自由に追加・削除・並び替え |
| プロフィール設定 | 表示名・アイコン画像の変更 |

## 4. 画面一覧

| パス | 画面名 | 認証要否 |
|------|--------|---------|
| `/` | ランディングページ | 不要 |
| `/login` | ログイン / アカウント登録 | 不要（認証済みは `/diary` へリダイレクト） |
| `/diary` | 日記一覧 | 必要 |
| `/diary/new` | 日記作成 | 必要 |
| `/diary/:id` | 日記詳細 | 必要（非公開は本人のみ） |
| `/diary/:id/edit` | 日記編集 | 必要（本人のみ） |
| `/public` | みんなの日記（公開一覧） | 不要 |
| `/public/:id` | みんなの日記（公開詳細） | 不要 |
| `/settings` | 設定 | 必要 |

---

## 5. 非機能要件

| 項目 | 内容 |
|------|------|
| レスポンシブ対応 | モバイル（375px〜）・タブレット・デスクトップに対応 |
| ダークモード | テーマ切り替え対応（ThemeProvider を利用） |
| セキュリティ | HTTPS 必須、httpOnly Cookie、CORS 設定 |
| ファイル保存 | サーバーローカルまたは外部ストレージ（初期実装はサーバーローカル） |
| ページネーション | 日記一覧・公開日記一覧は 20件/ページ |
| バリデーション | フロントエンド（Zod + TanStack Form）・バックエンド（Zod）双方で実施 |
