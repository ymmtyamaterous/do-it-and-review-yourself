## 1. 画像・音声ファイルアップロード機能

### 現状

- DB スキーマ (`diary_media` テーブル) は実装済み
- API・フロントエンドの実装はゼロ

### 方針

- ファイルはサーバーのローカルストレージ（`/uploads/` ディレクトリ）に保存する
- Hono の `multipart/form-data` ハンドラーで受け取る（oRPC ではなく Hono ルートとして追加）
- DB の `diary_media.url` には `/uploads/{uuid}.{ext}` 形式のパスを保存
- ビルド済みバックエンドの静的ファイル配信として `/uploads` も公開する

### 実装ステップ

#### 1-1. バックエンド (apps/server)

| # | 内容 |
|---|------|
| 1 | `src/uploads.ts` を作成し、`/api/diary/:diaryId/media` へのファイルアップロードエンドポイント (POST) を実装 |
| 2 | `src/uploads.ts` に `/api/diary/:diaryId/media/:mediaId` の削除エンドポイント (DELETE) を追加 |
| 3 | `src/index.ts` でアップロードルートをマウント・`/uploads` ディレクトリを静的配信 |

ファイル保存ロジック:
1. `bun` の `File` API でバイナリを受け取り、`uploads/` ディレクトリに `{uuid}.{ext}` で保存
2. `diary_media` テーブルに `id`, `diaryId`, `type`, `url`, `filename`, `mimeType`, `sizeBytes`, `order` を INSERT

#### 1-2. API ルーター (packages/api)

| # | 内容 |
|---|------|
| 1 | `diary.ts` に `getMedia` プロシージャを追加（指定 `diaryId` に紐づく `diary_media` 一覧を返す） |

#### 1-3. フロントエンド (apps/web)

| # | 内容 |
|---|------|
| 1 | `diary-form.tsx` にメディアアップロードセクションを追加（ファイル選択 UI、プレビュー表示、削除ボタン） |
| 2 | 日記の新規作成・編集後に `diaryId` が確定してからアップロードを実行する処理を実装 |
| 3 | 日記詳細画面 (`diary/$id.tsx`) に添付メディアの表示セクションを追加（画像: `<img>`、音声: `<audio>` タグ） |

### 制約・考慮事項

- 許可 MIME タイプ: `image/jpeg`, `image/png`, `image/gif`, `image/webp`, `audio/mpeg`, `audio/wav`, `audio/ogg`, `audio/mp4`
- 1 ファイルあたりの上限: 10MB
- アップロードは日記の保存後に実施（先に diaryId を確定させる）
- 公開日記でも `diary_media` は `fieldVisibility` に関係なく全件非公開扱いとする（将来拡張余地を残す）

## 2. モバイルヘッダーの改善

### 現状

PC: `[ロゴ] [みんなの日記] [わたし日記] [モード切替] [ユーザーメニュー]`  
モバイル: 同じ構成のままで横幅が足りない

### 方針

- `md` 未満（モバイル）ではナビゲーションリンクを非表示にし、ハンバーガーメニューに格納する
- `ModeToggle` と `UserMenu` は常時表示（アイコンのみなので小さい）

### 実装ステップ

| # | ファイル | 内容 |
|---|----------|------|
| 1 | `packages/ui/src/components/` | `sheet.tsx` を shadcn/ui から追加（スライドインメニュー） |

| 4 | Sheet の内部にナビゲーションリンクを縦並びで配置 |

## 3. カレンダービュー（日記一覧）

### 現状

- 日記一覧はリスト + ページネーション + 検索のみ

### 方針

- 一覧ページ上部にリスト表示 / カレンダー表示を切り替えるタブを配置
- カレンダーは外部ライブラリ `react-calendar` を採用（軽量・日本語対応）
- カレンダー上の日付に日記が存在する場合はドットインジケーターを表示
- 日付セルをクリックするとその日の日記詳細へ遷移（または日記がなければ新規作成へ）

### 実装ステップ

#### 3-1. API (packages/api)

| # | 内容 |
|---|------|
| 1 | `diary.ts` に `listByMonth` プロシージャを追加（`year`, `month` を入力として、その月の日記の `date` と `id` の一覧を返す） |

#### 3-2. フロントエンド (apps/web)

| # | 内容 |
|---|------|
| 1 | `bun add react-calendar` でパッケージを追加 |
| 2 | `src/components/diary-calendar.tsx` を新規作成（カレンダー表示コンポーネント） |
| 3 | `routes/diary/index.tsx` でビュー切替タブ（`Tabs` コンポーネント）を追加し、リスト / カレンダーを切り替え |
| 4 | カレンダー月変更時に `listByMonth` を呼び出して日記存在日付を取得 |

## 4. 日記詳細画面のレイアウト変更

### 現状

全フィールドが縦一列で表示されている。

### 目標デザイン（detail.png より）

```
┌──────────────────────────────────────────────┐
│ 2026-05-11                          🔒 非公開 │
│ [タイトル（大きく）]                           │
├──────────────────────────────────────────────┤
│ 📅 出来事                                    │
│    本文テキスト                               │
├──────────────────┬───────────────────────────┤
│ ☆ 良かったこと  │ ☆ 良かったこと            │
│    本文テキスト  │    本文テキスト            │
├──────────────────┼───────────────────────────┤
│ 💡 学んだこと   │ ✏ 自由記述欄              │
│    本文テキスト  │    本文テキスト            │
├──────────────────┴───────────────────────────┤
│ ✏ 自由記述欄                                 │
│    本文テキスト                               │
├──────────────────────────────────────────────┤
│ ♡ 健康・習慣チェック                          │
│ ✅ 筋トレ  ✅ 学んだこと  ☐ 健康・習慣チェック │
└──────────────────────────────────────────────┘
```

### 方針

- `diary/$id.tsx` のメイン表示カードを grid レイアウトに変更
- フィールドごとに「幅占有率」を定義してグリッドに配置
  - 全幅: 出来事、感謝、自由記述欄（フリー）、習慣チェック
  - 2 カラム: 良かったこと × 2、学んだこと + 自由記述欄（メモ）
- 空フィールドは非表示（現行動作維持）
- `fieldVisibility` で非公開設定のフィールドは他ユーザーには非表示（現行動作維持）

### 実装ステップ

| # | ファイル | 内容 |
|---|----------|------|
| 1 | `apps/web/src/routes/diary/$id.tsx` | メインカードを `grid grid-cols-2 gap-4` に変更 |
| 2 | 各フィールドのセクションに `col-span-1` または `col-span-2` を割り当て |
| 3 | アイコン + ラベル + テキストの小カードスタイルを定義 |
| 4 | 習慣チェックリストを横並びグリッドで表示（現状は縦一列） |
